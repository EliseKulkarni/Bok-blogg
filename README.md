# bokblogg

Statisk bokblogg som henter bokanmeldelser fra Notion og bygger seg selv på schedule.

Status: under oppsett (Fase 1 av 4 fullført — Notion-tilkobling verifisert).

## Stack

- [Astro](https://astro.build) + TypeScript
- Notion som CMS (`@notionhq/client`)
- GitHub Actions (bygg på schedule) + GitHub Pages (hosting)

Full oppsettguide og lokal kjøring legges til i Fase 4.
